we designed primers to introduce the single base changes to the PTGS1 insert inside a pCMV vector using JetPrime mutagenesis kit.

# Mutagenesis of to PTGS1 c.1565 17.09.2024

|   |   |   |
|---|---|---|
|Component|Amount 1x|2x|
|10X AccuPrime Pfx Reaction Mix|5 µL|10|
|Forward primer (10 µM)|1.5 µL|3|
|Reverse primer (10 µM)|1.5µL|3|
|dNTP mix (10 mM each)|1 µL|2|
|10X Enhancer|1 µL|3|
|**PfuUltra II Fusion Buffer**|5 µL|15|
|Plasmid DNA (50 ng/µL)|1|2|
|Nuclease-free water|1|2|
|DNA Methylase (4 U/µL)|1|2|
|**25X SAM**|2|4|
|**AccuPrime Pfx  polymerase(2.5 U/µL)**|0.4|0.8|
